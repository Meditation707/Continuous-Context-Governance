# Repository Architecture & Standards

### Primary Objective
This repository is the single authoritative artifact for the project[span_18](start_span)[span_18](end_span). The objective is that a future assistant can reconstruct the project with negligible information loss using this document alone[span_19](start_span)[span_19](end_span). If information exists only in conversation, the repository is incomplete[span_20](start_span)[span_20](end_span).

### Project Operating System
*   **Primary Rule:** The repository is the project; conversation is temporary, while the repository is permanent[span_21](start_span)[span_21](end_span).
*   **Repository First Rule:** The moment a discovery is ratified, the repository becomes stale, and no further development should continue until it is updated[span_22](start_span)[span_22](end_span).
*   **Information Preservation Rule:** If a discovery changes reasoning, drafting, architecture, calibration, methodology, or repository structure, it must immediately become part of the repository[span_23](start_span)[span_23](end_span).
*   **Compression Rule:** Compression shall never reduce explanatory power or remove derivations, reasoning, architectural constraints, drafting methodology, assistant calibration, or ratified principles[span_24](start_span)[span_24](end_span).
*   **Historical Integrity:** Nothing is deleted; material is only ratified, superseded, or rejected with recorded reasoning[span_25](start_span)[span_25](end_span).

### Repository Integrity Verification Tests
Before ending any work session, the repository must pass the following checks[span_37](start_span)[span_37](end_span):
*   **State Test:** Does it capture the exact current project state?[span_38](start_span)[span_38](end_span)
*   **Knowledge Test:** Does it preserve every ratified principle?[span_39](start_span)[span_39](end_span)
*   **Method Test:** Does it preserve the reasoning methodology?[span_40](start_span)[span_40](end_span)
*   **Architecture Test:** Does it preserve repository architecture?[span_41](start_span)[span_41](end_span)
*   **Calibration Test:** Does it preserve assistant operating instructions?[span_42](start_span)[span_42](end_span)
*   **Recovery Test:** Could a new assistant reconstruct the project from this repository alone?[span_43](start_span)[span_43](end_span)
*   **Compression Test:** Has explanatory power been preserved?[span_44](start_span)[span_44](end_span)
*   **Repository Test:** Does anything essential remain only inside conversation?[span_45](start_span)[span_45](end_span)
